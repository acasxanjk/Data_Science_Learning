# Data Science Learning

This repository documents my learning journey in Python data analysis, data visualization, and introductory machine learning.

## Topics

- Python fundamentals for data analysis
- Matplotlib data visualization
- Pandas and NumPy
- Introductory machine learning

## Environment Setup

Create and activate the Conda environment:

```bash
conda env create -f environment.yml
conda activate data-learning
```

Start JupyterLab:

```bash
jupyter lab
```
